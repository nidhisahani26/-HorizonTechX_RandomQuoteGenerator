# 💬 Random Quote Generator

## Overview
A beautiful quote generator app that displays random inspirational quotes with filtering and sharing capabilities.

## Features
✨ **Random Quote Display**
- Get random quotes on button click
- 10+ pre-loaded inspirational quotes
- Smooth quote transitions
- Author attribution for each quote

🎯 **Quote Filtering**
- Filter by categories
- Quick category switching
- Default shows all quotes

📋 **Sharing Features**
- Copy quotes to clipboard
- Tweet directly to Twitter
- Beautiful gradient UI

## Technologies Used
- HTML5
- CSS3
- Vanilla JavaScript
- Twitter API Integration
- Mobile-friendly design

## How to Use

### Get a Quote
1. Click "🎲 New Quote" button
2. Random quote displays instantly
3. See the quote text and author

### Copy Quote
1. Click "📋 Copy" button
2. Quote is copied to clipboard
3. Paste anywhere you want

### Share on Twitter
1. Click "𝕏 Tweet" button
2. Opens Twitter with quote text
3. Author name included

## Quote Categories
- Inspirational - Motivational quotes
- Success - Achievement quotes
- Wisdom - Wise quotes
- All - View all quotes

## Installation
1. Download files:
   - index.html
   - style.css
   - script.js
2. Place in same folder
3. Open index.html in browser
4. Start getting inspired!
